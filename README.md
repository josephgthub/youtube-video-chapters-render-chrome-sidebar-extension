# youtube-video-chapters-render-chrome-sidebar-extension
Chrome extension that auto-detects and displays YouTube video chapters (creator-made, auto-generated, or AI-generated) in a clean sidebar — with custom chapters, progress-bar navigation, sync, history, and search.
